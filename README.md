# English

# Crystal Space

Hello! 

This is my first video game developed in Unity. It’s inspired by the classic game **”Pong”**, but set in space.


## Game Description
Both opponents will control a reinforced spaceship to face each other. They must prevent the atomic crystal meteor from landing on their side before their impending explosion.
## Game Rules
Players must score a point by getting the meteorite past the opponent's boundary. There exists a time limit. If the timer hits 0 before anyone manages to score one point, the round goes to the player who doesn't have the meteorite on their side.
​Both players' scores and the remaining time are shown on an in-game scoreboard.


**Note:**
Both the maximum time to score and the total number of rounds to play can be set up from the ***Settings*** menu.
## Mechanics and Effects
**Meteor Speed Increase:**
   * The meteor increases in speed over time or with each bounce.


**Interactive Color Effects:**
  * Spaceships change colors randomly when hit by the meteor or when crashing into the map boundaries. In the latter case, they will turn a dull color.
## Customization


The ***Settings*** menu allows players to customize the following attributes from each player:


* *Speed*
* *Length*
* *Color*


**Note:** The color can only be changed between the default color and **red**, **green** or **blue**.


## Controls
| Movement | Player 1 | Player 2 |

| **Up** | `W` | `Up Arrow` |
| **Down** | `S` | `Down Arrow` |
| **Left** | `A` | `Left Arrow` |

# Español

# Crystal Space

Hola!

Este es mi primer juego desarrollado en Unity. Está inspirado en el clásico juego **"Pong"**, pero ambientado en el espacio.


## Descripción del Juego
Ambos contrincantes utilizarán una nave reforzada para enfrentarse entre sí. Tendrán que evitar que el meteoro de cristal atómico no acabe de su lado antes de su inminente explosión.
## Reglas del Juego
Los jugadores deberán anotar un punto al hacer llegar el meteoro al límite del lado del contrincante.
Existe un límite de tiempo para anotar. Si este llega a 0 antes de que un jugador logre anotar un punto, se le dará la victoria de la ronda a quién que no posea el meteoro de su lado. 
Los puntos de cada jugador, así cómo el tiempo restante del contador se muestran durante la partida en un marcador.


**Nota:** 
Tanto el tiempo máximo para anotar, cómo la cantidad de rondas a jugar se pueden configurar desde el menú ***Settings***.
## Mecánicas y Efectos
**Aumento de Velocidad del Meteoro:** 
  * El meteoro incrementa su velocidad con el paso del tiempo o con cada rebote.


**Efectos de Color Interactivos:**
  * Las naves cambian de color de forma aleatoria cuándo son golpeadas por el meteoro o al chocar contra los límites del mapa. En caso de esto último las mismas se tornarán de un color opaco.
## Personalización


En el menú de ***Settings*** se permite modificar las siguientes características de cada jugador:
* *Velocidad*
* *Largo*
* *Color*


**Nota:** Este último sólo puede variar entre el color por defecto y ***rojo***, ***verde*** o ***azul***.
